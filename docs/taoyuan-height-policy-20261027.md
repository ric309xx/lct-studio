## 資料契約

- 原始測量 CSV、控制點、模型與地籍幾何保持原樣。原始 h 觀測若存在就保留，不需把每個點再持久化另一份推算高度。
- 本專案已確認來源為 EPSG:3826+8904；平面 CRS 與高程基準分開記錄。對外高度使用 TWVD2001 正高 H，內部定位使用 h = H + N；反向輸出使用 H = h − N。
- 此次 N 是同名點、平面位置相符的原始 h/H 成對資料所求局部常數，不是官方全臺網格，也不是把全球地形差值當作 N。不同批次獨立設定。
- 正式測量／驗收仍需確認控制點、基站改正與高程基準，或採經核定的大地起伏模型；本次不宣稱達成正式高程精度驗收。
- 未知來源、方法不支援、證據不足或 root tileset SHA256 不符，保留原模型、不猜 +20 m，介面標示待確認，不能把未知值輸出成看似有效的正高或 0。

## 實作與保護

- `heightReference.ts` 統一方法、反算與一次性轉換。一次剛體 local-up 平移只修改 tileset.modelMatrix，不縮放、不修改 source XY / Z / 面積；WeakMap 阻止同一物件重複轉換。已是 h 的模型不再平移。
- `taoyuanHeightProfiles.json` 只含批次、來源基準、root/GCP SHA256、N、控制數、框架證據與方法版本 `paired-controls-local-constant / 20261027-local-v1`。root 指紋不等於整個網格所有檔案的完整性驗證；換模型應另建版本並重新驗證。
- 模型載入時先檢查既有授權取得的 root bytes，再轉換，之後才取樣地籍地面／校準綠色投影。來源視角高度、地標輸入與視角複製使用同一轉換；未知基準的地標變更及有效高度輸出受阻擋。
- UI 顯示來源正高、局部換算狀態與「背景地形僅供定位」。不提供使用者任意高程偏移或額外視角調整工具。
- 全量控制點配對留在 analysis，不放入一般 viewer bundle。僅本機明確診斷 build 可包含控制點射線工具；一般 build 使用空診斷模組，另驗證無原始控制點 chunk。診斷射線必須命中指定 tileset，拒絕全球地形或其他物件回傳。
- `audit_taoyuan_height_sources.mjs` 為只讀來源稽核；精確 ID + XY 配對、記錄明確別名與資料 SHA，重複觀測去重，不把缺漏當成零。來源 CSV 沒有被改寫。
