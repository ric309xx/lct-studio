# 2026-10-28 檢視器 Git 更新範圍

使用者已確認本機效果並要求推送 Git。本批包含：

- 模型正高／橢球高的批次換算與版本比對；來源正高保留，未知基準標示待確認，不以全球地形強制校正模型。
- 國土正射底圖預設、精簡側欄與問號說明。
- 點選固定座標、緯度／經度複製、模型表面拾取、距離與面積顯示、分色、描邊文字及頂點編輯。
- 案件控制點唯讀介面、來源座標及照片查詢；原始資料與照片不隨 Git 發布。
- 「回到模型」回復案件初始轉向完成的鏡頭與旋轉中心。

## 私人資料及本機依賴

本批不包含 `.env`、密碼、控制點原始配對資料、私人照片／catalog、本機截圖、量測暫存、OneDrive 衝突副本、舊 lazy chunks 或較早的交接文件改動。

本機高程診斷改為僅在明確啟用且位於 127.0.0.1 時按需讀取外部 analysis 資料。一般 TypeScript／Vite 建置不再要求這些私人原始 JSON；一般 bundle 仍使用空診斷模組。缺少本機控制點套件時，專項本機資料驗證測試會跳過，其餘使用合成測試資料。

`scripts/prepare_viewer_control_points.mjs` 與高程稽核腳本仍需要安全移轉的原始來源及本機路徑；不是下載 Git 就會取得私人資料。正式控制點資料日後需另行授權上傳既有私人 R2，不能改成公開靜態檔案。

本批 Git 提交不包含模型／照片 R2 上傳或 Worker 部署，也不宣稱已驗證正式站的自動部署結果。
