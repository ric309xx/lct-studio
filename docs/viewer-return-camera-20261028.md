# 案件初始鏡頭與旋轉中心還原

- 「回到模型」還原案件進入後自動轉向的終點，包含世界座標位置、方向、透視投影與縮放。不是重新執行通用包圍球飛行。
- 終點在動畫開始前計算並獨立保存；使用者提早中止轉向，仍可回到原定完成鏡頭。
- 清除左鍵點選產生的臨時旋轉中心，並把中鍵旋轉中心重設為當次案件初始轉向中心。多筆地籍的案件沿用完整案件的進入中心。
- 同一案件內切換地號，不覆寫當次案件的初始鏡頭。更換案件／重建 Viewer 時清除。
- 直接連結／重新整理也使用案件既有的個別轉向設定。其他專案保留原本回到模型方式。
- 僅改鏡頭與滑鼠導航，不改模型、地籍、來源座標、高程、量測紀錄或面積。
