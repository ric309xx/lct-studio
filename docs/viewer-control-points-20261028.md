# 3D 案件控制點圖層

程式、測試與操作文件納入本次 Git 更新；控制點原始資料、catalog 與照片仍僅保存在本機，未上傳私人 R2。Git 更新不代表正式站的控制點資料已發布或驗證。

## 資料與範圍

- 使用 8 個模型批次的原始 Terra `AT/gcp_points.json`，包含控制點與檢核點，共 37 筆批次點位。識別使用「批次 ID + 原始模型點號」，不因同名就合併不同批次的資料。
- 所有 GCP 原檔 SHA256 均與既有高程稽核一致；座標保留模型來源 E/N/H，不用模型取點或照片 GPS 覆寫。
- 平面 EPSG:3826 與垂直 EPSG:8904（TWVD2001 正高）分開保存。圖上經緯度由來源 E/N 反算；沒有新增坐標曆元轉換。
- 3D 定位只使用與目前模型一致、通過既有高程驗證的 H→h 換算；未知模型高程不猜零或固定 +20 m。總覽地圖僅使用水平位置。
- 依既有 20261011／20261013 照片分類清單精確對應點號，來源照片及本機副本逐檔核對 SHA256。共 134 張唯一照片；9 筆批次點位無可確認照片，介面顯示待補。CLR16 不借用 CL16 的照片。
- LINE 照片無原始 EXIF 拍攝時間，不以整理日期、下載或上傳時間冒充拍攝日期。

## 本機準備

執行 `node scripts/prepare_viewer_control_points.mjs`。只讀原始測量／GCP／照片，輸出至已忽略的 `.local/private-control-points/taoyuan-building-overlay/`。

本機 Python HTTP 入口只綁 127.0.0.1。控制點套件只供 loopback 預覽，不是受保護的正式檔案服務，請勿將整個工作目錄公開架站。

## 介面

- 案件總覽與 3D 左側均有「顯示控制點」，預設關閉；目前選案時依所在模型批次篩選，未選案可看全部批次。
- 可按「查看點位範圍」或從清單選擇點位；圖面紫色標記可點選查詢。點位座標是來源成果，不是滑鼠讀值。
- 照片只在點位選取後載入，支援點擊放大、關閉與 Escape。切換點位、關閉圖層或離開專案會撤銷照片 Object URL 及事件監聽。
- 圖層為唯讀，不會改動來源控制點、模型、地籍、面積或量測標註。

## 私人資料發布界線

一般 bundle 不匯入原始控制點 JSON、照片或本機絕對路徑；保留原本診斷模組不進入正式 bundle 的檢查。

預覽載入也先核對既有專案授權。非 loopback 網址則只使用既有私人專案 Bearer Resource，從 `/projects/taoyuan-20261006/tiles/controls/v1/` 讀取；不提供公開 JSON／照片回退路徑，也不任意信任 catalog 內的遠端網址。

本次沒有把套件上傳 R2。若日後要正式發布，需先另行授權發布本套件，逐檔驗證私人存取與下載校驗；目前正式雲端若無資料，應明確顯示無法載入，不冒用本機資料成功狀態。
