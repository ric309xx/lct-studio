## 可重建檔案

- `parcel-inputs.json`：由截圖逐欄核對的土地資訊、查詢點與 DXF handle。
- `import-audit.json`：來源 SHA-256、幾何／登記面積、內點及 DEM 採樣結果。

- `survey-reference-audit.json`：外業 CAD 雜湊、閉合處理與逐地號交集稽核；原始 CAD 不發布。
- 1153：執行 `scripts/prepare_shuangling_model_1153.py --packages <既有地理套件目錄> --work <本機檢核目錄>` 生成 5 cm 彩色點雲俯視與候選圖，檢查候選 1 為連續屋頂／雨遮後，另加 `--publish-candidate 1` 寫入本機網站。`model-1153-audit.json` 保存來源 LAS 的 SHA-256、判讀條件與平面幾何。若原始 LAS 更新，需先使用新的檢核目錄重建，不沿用舊快取。
- `viewer-source/src/shuanglingGround.json`：1121 的 DEM 道路剖面、分段地籍面及模型高程校準採樣點。
- `viewer-source/src/taoyuan1013Parcels.json`：兩層選單、地號資訊、模型相對路徑及定位點。
- `3d-viewer/overlays/taoyuan-1013/block-*.geojson` 與 `viewer-source/public/overlays/taoyuan-1013/`：三區展示圖層。
- 完整模型檢核表、上傳進度及彩色 LAS 俯視檢核圖留在本機 `.local/taoyuan-1013-work/`，不提交原始模型或中間資料。
