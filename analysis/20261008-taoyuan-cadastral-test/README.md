# 桃園三維地籍 OBJ／DXF 占用面積測試

測試日期：2026-10-08  
來源：`D:\DATA\WORK\20261006桃園三維地籍\02成果`

## 輸入盤點

- `1007.dxf` / `1007.dwg`：DXF 內有 2 個封閉 `POLYLINE`，圖層名稱皆為 `Unknown_Area_Type`，沒有地號文字。
- `terra_obj/metadata.xml`：座標系統 `EPSG:3826+8904`，原點為 `272175.20775782375, 2761986.8015364651, 218.03200000030279`。
- `BlockRA.obj`：254,326 頂點、502,556 三角形。
- `BlockRX.obj`：184,592 頂點、365,421 三角形。
- 未提供獨立 DSM、DTM 或正射 GeoTIFF；正射檢核圖由 OBJ 紋理投影產生。

## 方法

1. 將 OBJ 局部座標加回 metadata 的 TWD97 原點。
2. 將兩塊模型的最高可見表面投影為 0.10 m 格網。
3. 以地籍周邊低高程表面擬合局部地面平面。
4. 分別以 1.5、2.0、2.5、3.0 m 離地高度作候選構造門檻。
5. 執行一格開閉運算並移除小於 1 m² 的完整連通區，再與各 DXF 多邊形相交計算。

## 影像判讀

- Parcel 1 的 1.96 m² 候選位於道路設施附近，不像建物，正式建物占用應先排除。
- Parcel 2 的最大連通區約 33.75 m²，位於東側建物與地籍相交處，為主要建物候選。
- Parcel 2 另有約 4.75 m² 與 3.13 m² 候選，俯視紋理顯示為樹木、車輛或其他非建物突出物，需人工排除。
- 若只保留 Parcel 2 最大建物候選，暫估建物占用為約 **33.7 m²**，占 Parcel 2 約 **12.5%**。
- DXF 沒有地號文字，尚不能判定 Parcel 1、Parcel 2 對應的正式地號。

## 限制

以上第一輪數值是 OBJ 模型推估，不是地籍鑑界成果。OBJ 高度本身無法分辨建物、樹木、車輛與路側設施，因此正式工程數值必須經俯視影像人工確認輪廓。後續新增 DEM／LAS 後的重算結果如下，應優先採用後續結果。
