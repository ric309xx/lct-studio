# 1015 富台段與東寮段新增套繪

本次匯入 2 批 Terra 模型、4 個地籍選取區塊、8 筆地號。既有桃園建物套繪專案共用一次網站登入；同區地號共用模型及地籍圖層。

## 坐標核對

使用者確認 CAD 為 TWD97。本次 `1015.dxf` 的 8 筆地籍多邊形，全部包含各筆查詢截圖上的 TWD97 點。直接將 CAD XY 按 EPSG:3826 與 Terra 成果核對，未再次進行 TWD67 datum 轉換、未做平移或面積縮放。

截圖中的 TWD67 是原始地籍成圖資訊；網站將此欄與 TWD97 整合坐標分開顯示。Terra 正射影像與彩色 LAS 檢視中，實測參考線大致對應屋頂／棚架位置，沒有明顯整體錯置。此為視覺套繪與地號對應核對，並非以獨立檢核點取得的公分級精度報告；屋簷、牆腳、遮蔽及影像重建誤差仍須複核。

## 占用分析

來源為 Terra 彩色 LAS 與模型；依使用者複核截圖，檢視不同高度的模型點，分開圈定上層建物、低棚、雨遮及 804-5 指定突出構造。實測 CAD 僅供位置參考，不用其建物線直接計算占用面積。

一般建物使用高於估計地面 1.5 m 的模型點及 0.1 m 投影格網。已確認低棚使用分層模型外緣、指定高度區間及模型支持的頂面擬合；804-5 降低高度門檻以納入較低的突出構造。東寮段 1507-1／1508-1 僅保留下方棚架，排除擦邊牆面。全部輪廓與 TWD97 地籍求交集，重疊投影取聯集且只計一次；比例分母採登記面積。

顯示改用連續封閉補色面；棚架採薄頂面，不從棚頂塗到地面或上方牆面。立面補色及缺面修補不另外累計面積。地面校準採多點一致值，排除少數打到車輛的高度探測點。
