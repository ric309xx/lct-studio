## 開發與驗證

### 點之記與批次下載（本機測試，尚未部署）

點位資料內的「下載點之記」可輸出 PDF、Word（DOCX）或含照片的 HTML。沿用精簡資訊表及位置圖，照片以橫式呈現，直式照片僅在輸出時旋轉，原檔不變；標題使用「點號（近照／遠照）」。預設 1 近照 + 4 遠照，也可選 1 + 1、全部照片或自行勾選。

批次操作：

1. 在點位清單或地圖按「批次點之記」。清單左側的勾選框只用於下載選點；上方資料集勾選仍控制地圖顯示。
2. 清單逐點勾選，或「全選篩選結果」（包含尚未載入清單的結果）。搜尋、切換資料集及切換手機清單／地圖時保留已勾選點位。
3. 按「地圖選點」後，點擊地圖標記可勾選／取消；已選點以橘紅外框標示。相近或重疊點位會開啟可多選的清單，並顯示資料集以區分相同點號。
4. 按「下載已選 N 點」或「下載 ZIP」，設定輸出格式、底圖及每點照片配置。每點產生獨立檔案，以資料集分資料夾，檔名前加唯一序號，避免同點號覆蓋。
5. ZIP 附「下載清單.csv」，記錄點位 ID、實際照片張數及不足提醒。照片不足時使用現有照片；位置圖或附件讀取失敗則不下載本次 ZIP，勾選保留可重試。可隨時取消產生。

「清空勾選」清除全部下載選點，「結束選點」回到一般查點；重新整理或登出也會清除勾選。地圖與照片生成在瀏覽器逐點處理，不修改點位資料；大量照片的處理時間及可用記憶體依裝置而異。

手機查點後 GPS 僅更新位置標記與距離，按「定位我的位置」才將地圖移至目前位置。右側點位資料可「收合／展開」，保留頁籤與尚未送出的內容。

此功能完成本機驗證後只提交 Git；Cloudflare Worker 仍需另外明確部署，Git 推送不會讓雲端系統出現新功能。

需要 Node.js 22+。相依套件已安裝，本機密碼及資料庫已初始化。

```powershell
cd D:\OneDrive\Antigravity\01_LCT\control-points
npm.cmd run build
npm.cmd run dev
```

在另一個終端機執行下列指令。驗證、匯入與備份會向本機服務登入；環境變數只提供本次程序使用，不寫入來源碼。

```powershell
$secure = Read-Host '輸入本機密碼' -AsSecureString
$env:LCT_INITIAL_PASSWORD = [System.Net.NetworkCredential]::new('', $secure).Password
npm.cmd run verify
npm.cmd run backup
Remove-Item Env:LCT_INITIAL_PASSWORD
npm.cmd run check-backup
npm.cmd test
```

`check-backup` 讀取最新 ZIP（亦可 `npm.cmd run check-backup -- 完整ZIP路徑`），還原到全新 `.local/recovery-*`，核對每筆欄位及每個物件 SHA-256，絕不覆蓋現有資料。
要讓還原資料取代使用中資料庫，應先關閉服務、保留原資料目錄，再調整儲存綁定；本版沒有一鍵覆寫還原。
`prepare_inputs.py` 用 openpyxl 讀取兩份使用者指定來源；`npm.cmd run seed` 匯入已準備的首批資料，重複來源會略過。
重新安裝時先 `npm.cmd ci`、建置，再提供上述密碼環境變數執行 `npm.cmd run setup`。現有環境不用重設。

## 雲端設定

網站最上方的小型「控制點」連結指向獨立系統，手機版位於選單按鈕旁：
https://lct-control-points.private-3d-viewer.workers.dev/

正式環境設定在 `wrangler.production.jsonc`，使用獨立的 `lct-control-points` D1 與私人 R2 儲存桶。
`wrangler.jsonc` 繼續作本機開發使用，兩份設定的資料互相獨立。
Worker 程式必須另外部署；單純推送 Git 只會更新網站原始碼與首頁入口。

```powershell
npm.cmd run build
npx.cmd wrangler deploy --config wrangler.production.jsonc
# 首次部署後上傳本機已設定的密碼雜湊與鹽值（不包含明文密碼）
node scripts/publish-secrets.mjs
```

首次初始化遠端空資料庫：
`npx.cmd wrangler d1 execute lct-control-points --remote --file schema.sql --config wrangler.production.jsonc`。
首批資料準備完成後，可提供密碼環境變數並把 `LCT_BASE_URL` 設為雲端入口，執行 `seed`、`verify`。
原始 Excel、點位資料、照片、密碼雜湊與憑證均不提交 Git。
登入資料、點表、附件、原始檔下載及備份均在伺服器驗證 session，登入前 API 回覆 401。

Google Drive OAuth 與相機 AR 尚未實作。
手機實體相機、定位與羅盤需要支援的瀏覽器及安全 HTTPS 來源，仍需 iPhone 實機驗證。
本機 `127.0.0.1` 只能在這台電腦存取，外出使用上方的 HTTPS 雲端入口。
AR 找點可在定位距離與方位的基礎上繼續製作，手機定位精度須在畫面明示，不能當作測量放樣成果。

## 地點搜尋（本機開發）

地圖上方可搜尋地標、路名或地址；選取結果後移動地圖，紅色標記表示搜尋位置。搜尋不更動控制點坐標或資料集篩選。
地點查詢透過登入保護的 `/api/places`，由 Worker 連線 Photon／OpenStreetMap；需要網路，收錄完整度與服務可用性依提供者而異。可加上縣市或行政區縮小結果。
只在使用者按搜尋或 Enter 時查詢，伺服器限制頻率並在私人 R2 快取結果 7 天。`GEOCODER_URL` 可設定相容 Photon 的其他服務端點，預設 `https://photon.komoot.io/api/`。
服務與 API 說明：https://github.com/komoot/photon 、https://github.com/komoot/photon/blob/master/docs/api-v1.md 。
像控點資料集 `image-control-202610` 使用金黃色標記與深色外框，清單圖示、資料集圓點及圖例同步顯示。

地圖近點選取：群聚保留代表點的標記與配色，旁邊以小數字顯示總點數（例如 2 代表兩筆），放大後顯示代表點點號；代表點優先採用控制點或一等水準點，其次為測量點位，標記位於代表點原坐標。點擊數字或相互重疊的點位圖示會列出可選點位，包含資料集、原點號與點況；同點號不同來源不會合併。即使坐標完全相同，仍能分別開啟。清單也提供「放大此範圍」，按 Esc／關閉或點擊地圖空白處可收起。

地圖操作：拖曳與滾輪不要求先取得鍵盤焦點，選點或關閉資料後可直接操作地圖。直接點地圖只開啟資料、保持目前視角；從清單選點立即定位，至少放大至 17 級，已放大更多則保留比例。觸碰／滾輪會中斷尚未完成的導航動畫。群聚圖示依群聚與點號顯示層級快取，資料或群聚更新時重建。
